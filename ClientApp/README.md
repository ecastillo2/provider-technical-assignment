# ClientApp Folder – Optional Frontend (React)

This folder is **optional** and intended for candidates who choose to implement the optional frontend dashboard using **React**.

Completing a React-based dashboard is **not required** and will not negatively impact your evaluation if skipped.

---

## Purpose

If you choose to use this folder, you may create a small, **read-only dashboard** that visualizes or summarizes provider and license information from the backend application.

This is an opportunity to demonstrate:
- Frontend development experience
- Full-stack integration
- Data interpretation and presentation skills

---

## What You May Do Here

- Initialize a React application
- Display data retrieved from backend APIs
- Show summaries such as:
  - Provider counts by status
  - Licenses per provider
  - Expired vs active licenses
  - Any other meaningful metrics
- Use simple charts, tables, or visual indicators

Any lightweight charting or UI library may be used.

---

## Expectations

- The dashboard should be **read-only**
- Data must come from the backend (no hard-coded data)
- Business rules (soft delete, license expiration) should not exist only in the UI
- Keep the setup simple and maintainable

Avoid complex tooling, frameworks, or multi-server setups.

---

## If You Do NOT Use React

If you choose not to implement the optional dashboard:
- This folder may be left empty
- No action is required
- There is no penalty for skipping this section

---

## Documentation Requirement

If you implement a dashboard, please describe in your root `README.md`:

- What data you chose to display and why
- How the frontend retrieves data from the backend
- How this could be extended with more time
